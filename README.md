# 🧠 IA Backend - Detector de Fatiga y Distracción del Conductor

Este repositorio contiene el "cerebro" del proyecto: el servidor de Inteligencia Artificial que procesa las imágenes en tiempo real utilizando **YOLOv8** y clasificadores **Haar Cascade** de OpenCV para detectar el estado del chofer (Normal, Dormido, Fatiga/Bostezo o Distraído con Celular).

---

## 🛠️ Requisitos e Instalación Global

Para que este proyecto funcione en sus computadoras, deben tener instalado **Python 3.8 o superior**. 

Abran una terminal dentro de esta carpeta (`CONDUCTOR`) y ejecuten el siguiente comando para instalar **TODAS** las dependencias necesarias de un solo golpe:

```bash
pip install flask ultralytics opencv-python numpy requests

para ejecutar todo hacer un
python server.py
en la terminal :)
